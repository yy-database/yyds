# v0.0.13

Join tables with `INNER JOIN`, answer session `SHOW` / `SET` and `@@` variables, and run `SELECT` without a `FROM` clause.

## Features

- Support `INNER JOIN` in MySQL and PostgreSQL gateways ([@aster](https://github.com/aster))
- Serve `SHOW` and `SET` session statements ([@aster](https://github.com/aster))
- Resolve `@@` system variables ([@aster](https://github.com/aster))
- Allow from-less `SELECT` with scalar builtins ([@aster](https://github.com/aster))

## Bug Fixes

- Parse prefix unary `+` and `-` in SQL expressions ([@aster](https://github.com/aster))

## Breaking Changes

None
