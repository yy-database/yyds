# v0.0.3

MongoDB clients can connect over OP_MSG, Redis gets more string commands, and the MySQL gateway runs real SQL.

## Features

- Add a MongoDB OP_MSG gateway ([@aster](https://github.com/aster))
- Run SQL through the MySQL gateway ([@aster](https://github.com/aster))
- Add Redis `TTL`, `TYPE`, `STRLEN`, `APPEND`, and multi-key `EXISTS` ([@aster](https://github.com/aster))
- Lower SQL onto the shared key-value executor ([@aster](https://github.com/aster))

## Bug Fixes

- Fix npm publish artifact names in the release workflow ([@aster](https://github.com/aster))

## Breaking Changes

None
