# v0.0.16

Homepage and console Web UI, a Python control-plane package, MongoDB `hello` / `ping` through `yyds start`, and real Node driver coverage. The monorepo splits into `projects/yyds.rs/` and `projects/yyds.ts/`.

## Features

- Ship `@yydb/yyds-webui` and bundle it from the CLI ([@aster](https://github.com/aster))
- Publish a YYDS homepage with welcome, documentation links, and a wire demo ([@aster](https://github.com/aster))
- Add the `yyds-pyo3` / `yyds` Python package skeleton ([@aster](https://github.com/aster))
- Serve MongoDB `hello` / `ping` through `yyds start --mongo-port` ([@aster](https://github.com/aster))
- Drive gateways with real Node clients (`mysql2`, `pg`, `node-redis`, `mongodb`) ([@aster](https://github.com/aster))
- Split the monorepo into `projects/yyds.rs/` and `projects/yyds.ts/` ([@aster](https://github.com/aster))

## Bug Fixes

- Build N-API from the crate directory so the `.node` artifact is produced in CI ([@aster](https://github.com/aster))
- Include the Python package sources in the wheel ([@aster](https://github.com/aster))

## Breaking Changes

- Catalog bytes follow the upstream VOS identity contract; older snapshot ledgers are rejected ([@aster](https://github.com/aster))
