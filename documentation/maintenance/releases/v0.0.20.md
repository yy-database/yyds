# v0.0.20

`yyds start` can load a catalog and mount MySQL/PostgreSQL SQL runtimes. Python binding checks gate npm publish.

## Features

- Load a catalog on start and mount SQL runtimes for MySQL and PostgreSQL ([@aster](https://github.com/aster))
- Run `check-python` as a publish gate ([@aster](https://github.com/aster))
