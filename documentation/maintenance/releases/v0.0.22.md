# v0.0.22

Publish catalogs from the CLI, start SQL with `--catalog-path`, and verify PostgreSQL/MySQL with real Python drivers in CI.

## Features

- Publish catalogs through `yyds catalog` and start SQL with `--catalog-path` ([@aster](https://github.com/aster))
- Run PostgreSQL and MySQL real-client suites in a dedicated CI job ([@aster](https://github.com/aster))
- Parse `CROSS JOIN` and chained set operations from upstream SQL ([@aster](https://github.com/aster))

## Bug Fixes

- Describe PostgreSQL bound writes from the real bound values ([@aster](https://github.com/aster))

## Breaking Changes

None
