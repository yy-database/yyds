# v0.0.1

First installable packages: Node bindings, Redis/MySQL/PostgreSQL gateways, catalog-aware SQL, and a local node you can start from npm.

## Features

- Ship `@yydb/yyds` with native Node bindings and a local node lifecycle ([@aster](https://github.com/aster))
- Add Redis, MySQL, and PostgreSQL gateways so ordinary drivers can connect ([@aster](https://github.com/aster))
- Plan SQL from the catalog and run it on the key-value store ([@aster](https://github.com/aster))
- Add the YY control-plane wire codec and listener ([@aster](https://github.com/aster))
- Publish Windows, Linux, and macOS platform packages ([@aster](https://github.com/aster))
