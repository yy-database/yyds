# v0.0.6

Queries that return many rows can scan ordered key ranges and merge results across shards.

## Features

- Scan ordered key ranges inside a namespace ([@aster](https://github.com/aster))
- Merge multi-shard scan results in the executor ([@aster](https://github.com/aster))
- Plan multi-row `SELECT` as a storage scan ([@aster](https://github.com/aster))
