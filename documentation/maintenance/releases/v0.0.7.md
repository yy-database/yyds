# v0.0.7

`BETWEEN` on primary keys and `LIMIT` are pushed into storage scans so large reads do less work.

## Features

- Support SQL `BETWEEN` with inclusive bounds ([@aster](https://github.com/aster))
- Push primary-key ranges and `LIMIT` into scan plans ([@aster](https://github.com/aster))
