# v0.0.18

Window functions, non-recursive CTEs, `EXISTS` / scalar subqueries, set operations, string and time helpers, and PostgreSQL `ON CONFLICT` / `RETURNING`.

## Features

- Evaluate `ROW_NUMBER`, `RANK`, `DENSE_RANK`, and partitioned aggregates over `OVER (...)` ([@aster](https://github.com/aster))
- Flatten non-recursive CTEs and filter-preserving derived tables ([@aster](https://github.com/aster))
- Materialize `EXISTS` and evaluate scalar subqueries ([@aster](https://github.com/aster))
- Support `INSERT … SELECT`, `ON CONFLICT DO NOTHING` / `DO UPDATE`, and `RETURNING` ([@aster](https://github.com/aster))
- Support set operations (`UNION`, `INTERSECT`, `EXCEPT`) ([@aster](https://github.com/aster))
- Evaluate string helpers (`SUBSTRING`, `TRIM`, `REPLACE`, `CONCAT`) and UTC time scalars ([@aster](https://github.com/aster))
- Report exact integer overflow as SQLSTATE `22003` ([@aster](https://github.com/aster))
