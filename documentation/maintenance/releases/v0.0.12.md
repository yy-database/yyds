# v0.0.12

SQL gets `GROUP BY` / `HAVING` (plus `NOT IN` / `NOT BETWEEN`). MySQL and PostgreSQL SQL runtimes mount through N-API. SQLite leaves the product surface.

## Features

- Aggregate with `GROUP BY` and filter groups with `HAVING` ([@aster](https://github.com/aster))
- Extend ordering and predicates with `ORDER BY`, `NOT IN`, and `NOT BETWEEN` ([@aster](https://github.com/aster))
- Mount SQL runtimes on MySQL and PostgreSQL N-API handles ([@aster](https://github.com/aster))

## Bug Fixes

- Fix disguise CLI `bin` field naming for npm packages ([@aster](https://github.com/aster))

## Breaking Changes

- SQLite crates, N-API surface, and publish entries are removed from YYDS ([@aster](https://github.com/aster))
