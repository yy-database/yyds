# v0.0.15

`SELECT DISTINCT`, real `GROUP BY` / `HAVING`, and NULL ordering that follows MySQL or PostgreSQL defaults (including `NULLS FIRST` / `NULLS LAST`).

## Features

- De-duplicate rows with `SELECT DISTINCT` ([@aster](https://github.com/aster))
- Group and filter with real `GROUP BY` / `HAVING` results ([@aster](https://github.com/aster))
- Honor dialect NULL ordering and explicit `NULLS FIRST` / `NULLS LAST` ([@aster](https://github.com/aster))
- Accept `GROUP BY` ordinals and aggregate-only `HAVING` ([@aster](https://github.com/aster))
- Bind select clauses from the SQL AST instead of rescanning statement text ([@aster](https://github.com/aster))
