# v0.0.17

Outer joins, `CASE` / `CAST`, `COUNT(DISTINCT)`, multi-row inserts, and MySQL/PostgreSQL driver compatibility fixes.

## Features

- Support `LEFT`, `RIGHT`, and `FULL` outer joins ([@aster](https://github.com/aster))
- Evaluate `CASE WHEN` and `CAST` expressions ([@aster](https://github.com/aster))
- Support `COUNT(DISTINCT column)` ([@aster](https://github.com/aster))
- Split and execute multi-row `INSERT … VALUES` ([@aster](https://github.com/aster))
- Persist PostgreSQL `search_path` and keep `server_version` consistent ([@aster](https://github.com/aster))

## Bug Fixes

- Advertise MySQL booleans as `TINYINT(1)` so drivers round-trip correctly ([@aster](https://github.com/aster))
- Track MySQL `IN_TRANS` status from the live transaction session ([@aster](https://github.com/aster))
- Apply dialect rules for integer division and division by zero ([@aster](https://github.com/aster))
- Set MySQL `NOT NULL` column flags from catalog nullability ([@aster](https://github.com/aster))

## Breaking Changes

None
