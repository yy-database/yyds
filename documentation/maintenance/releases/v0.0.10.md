# v0.0.10

Nodes open with a published catalog. SQL rows encode with catalog field types. MySQL and PostgreSQL transactions bind to real storage transactions.

## Features

- Load `yyds-catalog` when a node starts ([@aster](https://github.com/aster))
- Bind MySQL and PostgreSQL transactions to storage transaction handles ([@aster](https://github.com/aster))
- Decode partial rows and keep `ORDER BY` aligned with catalog types ([@aster](https://github.com/aster))

## Bug Fixes

- Encode and decode SQL rows from catalog field types instead of loose inference ([@aster](https://github.com/aster))
- Keep the full predicate on `UPDATE` and `DELETE` plans ([@aster](https://github.com/aster))

## Breaking Changes

None
