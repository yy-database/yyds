# v0.0.2

Every npm package moves under `@yydb/*`. Start a local node with the TypeScript CLI; the old standalone CLI crate is gone.

## Features

- Add the `@yydb/yyds` TypeScript CLI for in-process local nodes ([@aster](https://github.com/aster))
- Publish packages under the `@yydb/*` scope ([@aster](https://github.com/aster))
- Keep SQLite as a snapshot inspection helper only ([@aster](https://github.com/aster))

## Bug Fixes

- Drop browser/wasm package entries that broke typecheck ([@aster](https://github.com/aster))

## Breaking Changes

- Package names now use `@yydb/*` instead of unscoped names ([@aster](https://github.com/aster))
- The standalone CLI crate is removed; use `@yydb/yyds` ([@aster](https://github.com/aster))
