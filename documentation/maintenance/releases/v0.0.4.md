# v0.0.4

Primary-key `INSERT`, `UPDATE`, and `DELETE` work through both MySQL and PostgreSQL gateways.

## Features

- Plan and run primary-key `INSERT` / `UPDATE` / `DELETE` ([@aster](https://github.com/aster))
- Accept MySQL `COM_QUERY` writes through the SQL planner ([@aster](https://github.com/aster))
- Run the same read/write SQL path on PostgreSQL simple query ([@aster](https://github.com/aster))
