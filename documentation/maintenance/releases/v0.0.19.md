# v0.0.19

Savepoints, single-level correlated subqueries, and case-insensitive string compare/sort/LIKE for default collations.

## Features

- Create, roll back to, and release savepoints ([@aster](https://github.com/aster))
- Execute single-level correlated `EXISTS`, `IN`, and scalar subqueries ([@aster](https://github.com/aster))
- Compare and sort strings case-insensitively for default collations ([@aster](https://github.com/aster))
- Allow richer numeric expressions in `ON CONFLICT DO UPDATE SET` ([@aster](https://github.com/aster))

## Bug Fixes

- Close PostgreSQL portals when their prepared statement is closed ([@aster](https://github.com/aster))
- Distinguish catalog construction failures from execution failures on the wire ([@aster](https://github.com/aster))

## Breaking Changes

None
