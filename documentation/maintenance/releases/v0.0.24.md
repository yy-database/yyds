# v0.0.24

Mixed `UNION` / `INTERSECT` / `EXCEPT` chains follow SQL precedence. `CROSS JOIN` returns a full Cartesian product.

## Features

- Fold chained set operations with `INTERSECT` precedence ([@aster](https://github.com/aster))
- Prove `CROSS JOIN` Cartesian products in conformance tests ([@aster](https://github.com/aster))

## Bug Fixes

- Point homepage copy at the locale keys the site actually ships ([@aster](https://github.com/aster))
- Assert the executor-backed Redis `MULTI` / `EXEC` path in integration tests ([@aster](https://github.com/aster))
