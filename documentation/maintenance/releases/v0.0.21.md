# v0.0.21

MongoDB insert/find/delete through the gateway, Redis `MULTI`/`EXEC` plus key expiry, and session `SET`/`SHOW` grounded in live gateway state.

## Features

- Implement MongoDB `insert`, `find`, and `delete` with namespace routing ([@aster](https://github.com/aster))
- Queue Redis `MULTI` / `EXEC` transactions and support `EXPIRE` / `TTL` ([@aster](https://github.com/aster))
- Keep MySQL autocommit and PostgreSQL `server_version` / `search_path` on real session state ([@aster](https://github.com/aster))

## Bug Fixes

- Reject unknown MySQL `SET` variables and validate session status flags ([@aster](https://github.com/aster))

## Breaking Changes

None
