# v0.0.11

Remote wire peers can be required to present a bootstrap token. Local transactions check for conflicts before commit.

## Features

- Require connection auth before accepting remote wire frames ([@aster](https://github.com/aster))
- Accept bootstrap tokens from config or `YYDS_AUTH_TOKENS` ([@aster](https://github.com/aster))
- Validate local transactions before commit (optimistic concurrency) ([@aster](https://github.com/aster))
- Add atomic batch execute and commit on the key-value executor ([@aster](https://github.com/aster))
- Start the wire server as part of node startup ([@aster](https://github.com/aster))

## Bug Fixes

None

## Breaking Changes

- Unauthenticated remote wire peers are rejected when bootstrap tokens are configured ([@aster](https://github.com/aster))
