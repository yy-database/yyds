# v0.0.23

`BYTEA` / `BLOB` keep raw bytes on PostgreSQL and MySQL, including NUL and non-UTF-8 payloads.

## Features

- Carry raw octets in the SQL value domain without UTF-8 loss ([@aster](https://github.com/aster))
- Round-trip binary parameters and results on PostgreSQL and MySQL ([@aster](https://github.com/aster))
- Cover binary payload cases across the SQL driver matrix ([@aster](https://github.com/aster))

## Bug Fixes

- Assert MongoDB CRUD on the wire instead of expecting blanket rejection ([@aster](https://github.com/aster))
- Retry icon registry installs when Windows reports a transient file lock ([@aster](https://github.com/aster))

## Breaking Changes

None
